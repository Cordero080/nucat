# Model Switcher — Stretch Goals

Hot-swap FBX characters on the fly.

---

## ✅ Implemented

- **Model dropdown** in GUI to switch between FBX files
- **Adaptive sampling** - auto-adjusts point density based on model size
- **Auto character sizing** - smaller models get smaller ASCII chars
- **Camera reframing** - auto-focuses on new model
- **Cube recalculation** - incubation chamber resizes to fit
